2. LEMMAS
--------------------------------------------------------------------------
Conventions: M a molecule (current, = M_pre), v an eps-atom, tame in every admissible decoration: all bonds at v carry one value
k0 (in Lean: all darts at v carry k0 up to orientation). C_1..C_c are the components of (v's component of M) - v that contain a
neighbour of v. b_i = number of bonds between v and C_i. s_i = #(bonds v->C_i) - #(bonds C_i->v). d_v = deg v.

L1 (flux pin) [PROVED]. For every (c_w)-decoration: sum_{w in C_i} c_w = -s_i k0.
  Proof: sum the conservation law sum_{l~w} zeta_{w,l} k_l = c_w over w in C_i. Internal bonds cancel. A bond between C_i
  and v contributes +k0 at its C_i end if it leaves C_i (enters v), and -k0 if it enters C_i. (Lean: G8 `sum_charges_eq_cross`
  with Y = C_i. The crossing darts are exactly the darts of C_i at v.)
  Consequence: if some s_i != 0, then k0 = -(sum_{C_i} c_w)/s_i is a function of the parameters (c_w) ("pinned").
  Conversely, if all s_i = 0, conservation alone does not determine k0. On 18126 random instances the row-space test agrees
  exactly with "some s_i != 0" (check_remtame.py T5).

L2 (dichotomy) [PROVED]. (a) d_v = 3 => pinned (sum_i s_i = outdeg - indeg = +-1, so some s_i != 0).
  (b) d_v = 4 (2 in, 2 out): pinned, or c <= 2. If all s_i = 0 then each b_i is even and >= 2, so 4 = sum b_i >= 2c.
  (c) d_v = 1, or d_v = 2 with both bonds in the same direction => pinned. (d) d_v = 2 with opposite bonds and c = 1: not pinned
  and Delta chi = -1. This sub-case never arises at Op 2's v3 or Op 4's v, which have degree >= 3 (DH23 L1777/L1781, G3 model);
  see Section 6.
  Random check, T5: every degree-3 atom is pinned. Every unpinned degree-4 atom has c <= 2.

L3 (erasure bookkeeping) [PROVED]. Erasing v (removing v and its d_v bonds, creating no alpha/beta atom) gives:
  Delta V = -1, Delta E = -d_v, Delta F = c - 1, Delta chi = c - d_v, Delta V_alpha = Delta V_beta = 0.
  Phi := 4V - 2E - 2(V_alpha+V_beta) rises by 2 d_v - 4 (+4 for d_v = 4, as G3 Good.eraseSt; +2 for d_v = 3).
  Hence (imperfect components) <= Phi/2 = R + sum over erasures of (d_v - 2).
  T3 and T5 check Delta chi = c - d_v.
