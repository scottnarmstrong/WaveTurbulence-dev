0. MODEL AND NOTATION
----------------------------------------------------------------------------------------------------------------
Exponents are log_L.  a = 2g0 + 5eta^2, b = g0 + 2eta^2 (g0 = gamma0 = min(gamma,1-gamma)), h = (gamma+3eta)/2,
T(Q,kappa) = L^{h - kappa*eta} Q  (the alpha label factor of excesseqn2), t = log_L T <= (-gamma+5eta)/2 < 0.
q = log_L Q in [-1, -gamma+eta] for every SG / alpha label.  W = delta^{-1} L^{-2gamma} (energy window).

Triangle v1 v2 v3 (G3: t0 t1 t2), bonds l3 = v1v2 (momentum a), l1 = v2v3, l2 = v3v1; it is a directed 3-cycle (each
triangle pair has opposite directions), gaps r1, r2, r3 = differences of consecutive momenta, r1 + r2 + r3 = 0,
energies E_j = 2 a.r_j + (quadratic in r), E1 + E2 + E3 = 0.

GHOST = triangle atom already cut (class alpha/beta, degree 2; its two darts are the two triangle darts).
G3 model (= DH23 L1777 reading "if deg v_j >= 3 then we cut"): ghosts are not cut; they are deleted with the triangle.
G = ghost set, N = non-ghost set, m = number of post components containing non-ghost halves f_j (m = 0 iff N empty).
Classification (DH23 L1777 / TARGET L2142, G3 triCls): f3 beta; f1 alpha iff f1~f3 or f1~f2; f2 alpha iff f2~f3.
  => #new alpha = |N| - m, #new beta = m.                                                         [PROVED, case check]
TRUE increments: DeltaF = m - 1, DeltaV_beta = m - g_beta (g_beta = #beta ghosts), Delta chi = m - 1 - |N|
  (E -3, V -g, F +DeltaF).  DH23 L1791's "DeltaF in {0,1,2}, DeltaV_beta = DeltaF+1, Delta chi = DeltaF-3" is the g = 0 case;
  with ghosts Delta chi = DeltaF - 3 + g and DeltaF = -1 is possible (triangle component).            [PROVED]

COUNT (DH23's method, made ghost-aware).  I <= #(a, r1, r2 admissible) * L^{(d-gamma) Delta chi} * delta^{O(1)} (log L)^{O(1)}.
  Blocks: the m post components (fixed flux r_P and energy E_P in a window of width <= nW: sum the atom equations over the
  component, as in DH23 L1788) plus one block per ghost (r_g = +-charge param, E_g in its window W).  B = m + g blocks,
  B - 1 independent relations.  Free gap vectors = 3 - B = #new alpha, and they can be taken to be the new alpha atoms'
  own gaps (|r_j| ~ Q_j; ball L^{-50eta}Q_j if kappa_j = 50).
  #a <= L^{d-1}(1 + L W/|r_P|) for any fixed block gap r_P  ->  exponent d + s(rho), s(rho) = min(0, max(-1, -2gamma-rho)).
  All block gaps are nonzero (SG labels, R29 nonzero gap at v3, N1 for beta ghosts, alpha-ghost labels), so |r_P| >= 1/L.
  Slab model brute-forced in d = 3 (slabcount.out): config A (|r| = 1/L, gamma = 0.6) slope log2(count(400)/count(200))
  = 2.80 = d+1-2gamma; config B (|r| ~ L^{-gamma+eta}) count/model in [0.78, 1.31] for L = 50..400.   [CHECKED, L <= 400]

4. QUESTION 4: A CHEAPER ROUTE (cut-all, TARGET Remark L2126)?  NO.
----------------------------------------------------------------------------------------------------------------
[PROVED, exponent arithmetic]  The deviation I of a decoration class is model-independent (the isolated remainder has one
decoration and chi = 0).  Under cut-all every ghost leaves an isolated beta atom, F_im(cut-all) = F_im(G3) + g_tot, and G2's
per-step RHS uses DeltaF_c = DeltaF + g, DeltaV_beta^{G2} = 3 - #alpha = DeltaV_beta(true, G3) + g.  Telescoping G2's bounds
(and using the exact A = 1 of each isolated atom) gives, relative to the needed a(R-1):
     per beta ghost  a - 2b = +eta^2          (no label to pay with; the -eta^3 per step cannot absorb it)
     per alpha ghost a - b + t_g = g0 + 3eta^2 + t_g, t_g <= (-gamma+5eta)/2  -> positive for 1/2 < gamma < 2/3 - O(eta).
So cut-all with G2's statement does NOT close (together2)/(together3), even with T_g.  The handoff's remark that cut-all
leaves "the same L^{(a-b)g} excess, again payable only with T_g" is too optimistic: T_g does not pay it for gamma < 2/3, and
beta ghosts leave L^{eta^2} each.  The information that closes the bookkeeping is exactly the charged statement of 3d
(which is a STRONGER per-step bound than G2's cut-all bound).  Cut-all saves nothing.
Other "cheap" options considered and rejected: skipping triangles with ghosts (then Op 3 can produce a perfect triangle
component with two alpha atoms, forbidden by finalmol and false for Prop 9.6 when 2gamma-1 < 4eta); relabelling v3 to be
the ghost (still needs the refund).

5. DEAD-HIT (coordinator add-on)
----------------------------------------------------------------------------------------------------------------
5a. Source reading.  [PROVED, by reading]  DH23 L1766 / TARGET L2131 define the counting quantity as the SUP over the
   CURRENT molecule's parameters (c_v, beta_v, k0); earlier values are parameters only while some present atom carries
   them as a charge.  DH23 L1803 ("the corresponding gap r must belong to a fixed ball") is justified by that definition
   only when the hitting cut is still carried by a present atom.  For a hit whose cut lost both halves (deleted as ghosts
   or with a triangle), the centre is a function of deleted data, not of the current parameters.  So DEAD-HIT is a genuine,
   minor exposition gap at DH23 L1784/L1803, TARGET Remark remiota L2150 (the nested-sum reading "earlier values stay
   fixed" is the intended meaning, but it is not the stated definition).
5b. Option 1 (carry dead charges): sound.  Extend the parameter vector of the state by the gaps of all dead cuts, define
   A_s = sup over (current params, dead values); at a deletion step the newly dead values are functions of the PRE
   parameters (deleted atom's charge = +-gap + c0, AtomRelU), so A_pre <= I * A_post still holds; Prop 9.6 needs uniformity
   in the extra parameters (it has it: they do not enter its hypotheses).  Cost: every UStep / UCtx / Adm restriction and
   the assembly chain carry a growing parameter list; G3's ghost pseudo-pairs (pushed into hist by triPost although DH23
   does not cut ghosts) would count as "cutting operations", a further deviation.
5c. Option 2 (alive-cut iota): sound and cheaper.  RECOMMENDED.  Define iota_v = 1 iff some cut performed before v's cut,
   still carried by a present atom AT THE TIME OF v's CUT, has 0 < |r_v +- r'| <= L^{-50eta} Q_v.
   Telescoping of kappa [PROVED]: kappa_v is computed once, at v's creation, and stored in v's class `.alpha Q kappa`.
     - creation step: kappa = 50 -> the hitting cut is alive, IotaUnif + AtomRelU give a centre that is a current parameter
       (existing G3 machinery, with the usual split of the class by (q, sign), <= 2n choices, absorbed by L^{-eta^3});
       kappa = 0 -> the generic count, valid without any iota information;
     - final use: Prop 9.6 product L^{-h + kappa eta}/Q with the same kappa; kappa = 0 needs only N2;
     - ghost deletion: refund T(Q_g, kappa_g)^{-1} with the same stored kappa_g.
   N2 (DH23 L1895, G3 HInv.N2) survives: it compares alpha atoms v1, v2 of M_fin; the earlier of their two cuts is carried
   by v1 (or v2), which is present from its creation to the end, hence alive at the later cut.  N1 is unaffected.
   A decoration whose only hit is dead now gets kappa = 0 and is covered by the generic (kappa = 0) count.
   G8 is unchanged (FinalDec.iota only compares atoms of M_fin).  Ghost pseudo-pairs in hist become irrelevant (their
   remainder is deleted at once, so they are dead from the start).
   G3 work: IotaHit's list = alive cuts at the time (record it in crec instead of the full hist); UStep kp = 0 condition
   "no ALIVE earlier cut hits"; N2 re-proof: replace the suffix argument (p1 :: vis1 <:+ vis2) by "p1 is in the alive list of
   v2's record", from the invariant "an atom present at the end was present, with the same record, at every later cut"
   (records are set once: alpha/beta atoms are never cut again; atoms are never re-created).
