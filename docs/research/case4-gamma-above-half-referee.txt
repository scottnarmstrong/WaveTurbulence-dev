3. CHECK 3: THE (Y)-REDUCTION TO T MINUS A BOND (note Step 3, Lemma 4.1)
=====================================================================================================================
Result: correct, modulo (M1).

3.1 Route structure.
    - Every complete sequence on a 4-regular graph ends in (Y2).  In a 4-regular graph each triple-bond atom has
      exactly one extra bond.  So (Y1) can only be L1929's "same third atom" case, which leaves that atom with
      degree 2.  Later (Y2) steps never touch it, and the end state T is 4-regular.
    - k <= 2.  A complete sequence never leaves a new triple bond: a triple bond formed by (Y2) is consumed by the
      next step.  A (Y2) adding a bond to an existing triple bond gives a quadruple bond, i.e. Q, which is not on a
      T-route.  So each sequence consumes one of the <= 2 triple bonds of M_1.
    - Only k = O(1) matters anyway.

3.2 ylem2 as stated (L1950).
    - Hypotheses: one (Y) sequence; for the second statement, the last operation is (Y2) and l is removed in the
      sequence.  There are none on the number of triple bonds and none on connectivity.
    - The note applies it only under these hypotheses.  The l-tracking in proof_steps.py
      (l := the sequence's LAST new bond whenever an endpoint of l is removed) matches the lemma's l'.

3.3 The counts behind both statements (my check of DH23's sketch).
    (a) First statement, and the note's "not removed" variant.
        - Given a decoration of M' (resp. M' \ l), the exits k_{l1}, k_{l2} are determined, since k_{l'} =
          k_{l2} + g(k_{l1} - k_{l2}) and k_{l1} - k_{l2} is fixed.
        - Fixing it uses DH21 Lemma 9.14, summed over the removed set R.  This holds when l is not incident to R,
          because R is still attached only through l1, l2.
        - R has 2n atoms and 4n - 1 internal bonds, and its 2n vector equations have one consistent dependency.
          So R carries 2n free vectors, which is -Delta chi.
        - The variant is the first statement with M \ l in place of M, word for word.
    (b) Second statement (l removed).
        - The restriction of an M \ l decoration to M' \ l' does NOT have fixed parameters at the attachment atoms:
          c' there depends on k_{l1}.
        - The correct reading of L1956 is therefore
              C(M \ l) <= #{decorations of R with BOTH exit bonds, using only R's constraints} . sup C(M' \ l').
        - R now has 4n - 2 internal bonds plus 2 exit bonds, and 2n independent equations: again 2n free vectors,
          which is -Delta chi.
        - DH23's order of counting (start at the atom that lost l, with Lemma A.3(2), then propagate) is needed.
        - Example: T_1 with l a copy of the triple bond.  #R = #(s, p, q, t) <~ delta^{-1} L^{2(d-gamma)} by A.3(2)
          at a_1, uniformly in the exit gap, even when it is 0.  The naive order (exits first by A.3(1), then the
          pair) loses L^{2 gamma - 1} at exit gap 0.
        So the statement is right, and the order matters.
    (c) Delta chi = -2n in each variant (E - 4n, V - 2n).
        - M^(i) and M^(i+1) are 4-regular and connected, so they have no bridge, and removing one bond keeps each
          connected (as the note says).
        - So F = 1 throughout.  Confirmed for all 8766 pairs by the re-run.

3.4 LG.
    - Props 10.1-10.4 carry a standing LG hypothesis (L1829), and ylem2 sits under it.
    - M_0 may contain degenerate epsilon-atoms, which are not LG (L1985 items (3)-(4)).
    - In the (Y2) case the proof only PRESERVES LG ("This will keep the LG assumption", L1954).  The counts use
      Lemma 9.14 and Lemma A.3(2),(3), none of which needs LG.
    - So Theorem A's claim "LG is not used" is right.  The note should say explicitly that this is why ylem2
      applies (Section 7.2).

4. CHECK 4: THE GAIN AT T MINUS A BOND (note Step 4, Lemma 2.1, (K2))
=====================================================================================================================
4.1 The system.
    - In T \ l*, the endpoints e, f of l* have degree 3 and share the other copy m.  Each has two bonds to g.
    - Removing e and f leaves g isolated: Delta chi = 2 - 5 = -3 (chi(T \ l*) = 3, chi(g) = 0).
    - The five vectors satisfy the atom systems at e and f.  Discarding g's constraints is an upper bound.
    - This is {(1,2,3),(1,4,5)} of L2096 and L2106.  m has opposite signs at e and f.  No tuple has three equal
      signs, because in, out <= 2.

4.2 Lemma 2.1 and the orientations.
    - Lemma 2.1 rests on the identity |k_i|^2 + |k_j|^2 - |k_l|^2 = |k|^2 - 2(k_i - k).(k_j - k) for
      k_l = k_i + k_j - k.  I re-derived it by hand.
    - check_reparam.py tests all 16 admissible sign patterns, 200 random integer instances each.  Result: 0 failures.
      The forms are x+y-v-z (1 odd in both), x+y-v (odd in exactly one; with A and B swapped, v -> -v), and x-v
      (odd in neither).
    - The maps (k_1, ..., k_5) -> (x, y, z) are injective.  The windows halve, and fewer constraints only
      enlarge the set.
    - Orientation: out(e) = a + (2 - c) = 2 forces c = a, and out(g) = (2 - a) + b = 2 forces b = a.  So T is cyclic
      (a in {0, 2}) or anti-parallel (a = 1).
    - Cyclic: m is the odd entry at e and at f, form (i), zeta = x+y-v-z.  Anti-parallel: m is odd at neither,
      form (iv), zeta = x - v.  I checked both by hand.  The mixed form (ii)/(iii) never occurs at T \ l*.

4.3 PROOF of the gamma > 1/2 branch of (countc2-1) (L2064-L2068) for the two forms that occur.
    Setup.
    - delta = 1, by splitting each window into delta^{-1} unit windows (cost delta^{-2}).
    - eps := 2 gamma - 1 in (0, 1).  Integer scale X = Lx in Z^d, |X - X^0| <= L.  rho := L^{2-2 gamma} = L^{1-eps},
      so |x.y - alpha| <= L^{-2 gamma} becomes |X.Y - A| <= rho.
    - Target exponent: 3(d - gamma) - gamma_0 = 3d - 1 - 2 gamma = 3d - 2 - eps.
    - Elementary per-vector bound, (P): for x != 0 with |x| ~ S,
          N_y(x) := #{y : |x.y - alpha| <= L^{-2 gamma}} <~ L^{d-1} min(L, 1 + L^{-eps}/S).
      (Fix the d-1 coordinates transverse to x's largest coordinate.)  The same holds for N_z with x - v in place
      of x.
    - Bilinear count, (Bi): sum_x N_y(x) <~ L^{2(d-gamma)} (log L)^C, uniformly in all centres.  Likewise for N_z.
      This is input (M4).

    (i) zeta = x+y-v-z (the same proof works for x+y-v).
      - Put s = x + y and w = s - v - z.  Then (s, z) -> (w, z) is injective, w ranges over a ball of radius 3, and
        constraint 2 reads w.z in a window.  By (Bi), #(s, z) <~ L^{2(d-gamma)}.
      - For fixed s, x.(s - x) = |s|^2/4 - |x - s/2|^2, so X lies in a spherical shell
        |X - S/2|^2 in [B, B + 2 rho].
      - Fix d - 2 coordinates (<= (2L+1)^{d-2} choices).  The planar section is an annulus of radius Q and width
        rho/Q (area ~ rho) inside a disc of radius L.
      - Lemma A.1(1) (L2029) gives
            # <~ min(rho + Q^{theta_c}, rho^{1/2} + L rho^{3/2} Q^{-1} + L rho^{1/2} Q^{-1/3}).
        * The first bound is the circle-problem error term, with theta_c = 2/3 for any centre.
        * The second is the convexity argument.  A planar section of angle << min(Q^{-2/3}, rho^{-1}) has hull area
          << 1, so its lattice points are collinear.  A line meets the annulus in <= 2 chords of length
          <~ rho^{1/2}, since Q.width = rho is fixed.  This also disposes of "nearly flat" huge-radius shells.
      - Split at Q = L^{(3/2)(1-c)} with c = eps/3: the first bound handles small Q, the second large Q.  Both are
        <= L^{1-c}.  (The three conditions are c <= eps, c <= 0.6 eps and c <= eps/3.)
      - Hence #x <~ L^{d-1-eps/3}.  So C_2 <~ L^{2(d-gamma)} L^{d-1-eps/3} = L^{3d-2-eps-eps/3}: saving eps/3.
      - With the exponent 7/11 that DH23 quotes (L2029, [Hux93]), the same split gives min(eps, 1/64); DH23
        writes min(10^{-3}, eps).
    (iv) zeta = x - v.  C_2 = sum_x N_y(x) N_z(x).  Write S = |x| and R' = |x - v|.
      (A) S <= L^{-eps} or R' <= L^{-eps}.  Use (P) and #{x : |x| ~ S} <~ (LS)^d.
          - Case S <= L^{-eps} < R':
              sum <~ L^{d-1} . sum_S (LS)^d L^{d-1} min(L, L^{-eps}/S)
                  <~ (log L)(L^{3d-2-d eps} + L^{3d-1-2d gamma}).
            Both terms are below L^{3d-2-eps} by at least L^{-(d-1) eps}.
          - Case R' <= L^{-eps} < S: the same, by symmetry.
          - Case both <= L^{-eps}: with S <= R' and S >= L^{-2 gamma},
              sum <~ (LS)^d L^{2d-2} L^{-2 eps} (S R')^{-1} <~ L^{3d-2-2 eps} S^{d-2} <= L^{3d-2-d eps}.
            With S < L^{-2 gamma} the total is <= L^{d(1-2 gamma)} L^{2d} = L^{3d-2 d gamma}, which is below the
            target since 2 gamma (d-1) > 1.
      (B) S, R' > L^{-eps}.  Then N_y, N_z <~ L^{d-1}.  Define theta_1, theta_2 >= 1 dyadic by
          N_y ~ L^{d-1}/theta_1 and N_z ~ L^{d-1}/theta_2.  Fix any kappa' in (0, 2 - 2 gamma), e.g.
          kappa' = 1 - gamma.
          - theta_1 > L^{kappa'}: sum <= L^{d-1-kappa'} sum_x N_z <~ (by (Bi)) L^{3d-2-eps-kappa'} (log L)^C.
            The case theta_2 > L^{kappa'} is the same.
          - Otherwise theta_i <= L^{kappa'} << rho, so estcross applies, to X for theta_1 and to X - LV for theta_2.
            It gives
                #{x in the cell} <~ rho^d + L^{d-2} rho^2 min(theta_1, theta_2)^2 (log L)^2.
            Contribution: <~ rho^d L^{2d-2} + L^{3d-4} rho^2 (log L)^2 = L^{3d-2-d eps} + L^{3d-2-2 eps}(log L)^2.
            There are (log L)^2 cells.
      Hence C_2 <~ (log L)^C L^{3d-2-eps} (L^{-eps} + L^{-kappa'}).
    Conclusion.
    - For both forms: C_2 <~ (log L)^C delta^{-2} L^{3(d-gamma) - gamma_0 - kappa(gamma)} with
      kappa(gamma) = min(eps/3, 1 - gamma).
    - This gives DH23's "-10 eta" as soon as 20 eta <= kappa(gamma), which holds since eta << _{d,gamma} 1 (L438).
      Note that eta << 1 - gamma is needed as well as eta << gamma - 1/2 (Section 7.1).
    - Sanity checks: at gamma = 1/2 the argument gives no saving, consistent with CASE4's sharp lower bound
      (Lemma 4.1).  The generic size is L^{3d-4 gamma}, i.e. saving eps.
