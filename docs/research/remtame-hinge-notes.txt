4.1 [PROVED + CHECKED] What goes wrong with single-atom erasures (check_damaged.py C0, C1).
  The tame neighbours of an erased tame atom keep k0 on their remaining bonds.  A tame atom of degree 2 with opposite
  bonds lying on a cycle is UNPINNED.  Erasing it loses L^{d-(d-gamma)} = L^gamma, and smoothing it can create a
  self-loop.  The two configurations below are CHECKED at graph level, with the count from the linear algebra.
  Garden realization is OPEN; it is not needed for any recommendation below.
  - C0: isolated tame eps-atom w of degree 0.  A = 1 against TARGET's R = 1 right-hand side L^{-eta^5 rho}, a failure
    by L^{eta^5}.  With the eta Z allowance (Z = 1) the bound holds.
  - C1: isolated tame double bond {u, v}.  A = #k0 * L^{-(d-gamma)} C1^{-1} delta^{1/2} ~ L^gamma.  No per-component
    bound holds.  As a cluster of its own (s = 2, e = 0, chi_K = 1, J = 1, unpinned), the local Phi credit a(s - 1) = a
    beats L^gamma only if 2 g0 > gamma, i.e. it fails for gamma >= 2/3 (E1 confirms this).
  In both cases the erasures that produced the configuration gained L^{-(d-2gamma)} or more, so the TOTAL is fine.
  The loss is visible only if each cluster is erased as a whole.  Under R27 item 1 as written (single atom), G3's
  HRunE ends with such components (FinalStructE allows them).  Under TARGET's literal case (i), the same chains give
  zero-gap beta-atoms (R27 F4).

4.2 [PROVED] The run model (Option B; DH23 Section 10.5(3)+(4)).
  Ops 1, 3 as in TARGET.  Op 2 on ELIGIBLE triangles only (3.4).  Op 4: beta-cuts with nonzero gap only (G3 HStep4 +
  NoBetaCut; this is exactly G8's FinalDec.noBetaCut).  Op 5: erase all tame eps-atoms, one cluster at a time.
  Invariant T0: no tame atom is ever cut, and before Op 5 no bond at a tame atom is removed.

4.3 [PROVED; CHECKED by C2 on 3000 random molecules/clusters, seed 7] The cluster-erasure lemma.
  Let K be a connected set of tame atoms of M.  Put s = |K|; e_int, e = # bonds inside K / from K to M - K;
  chi_K = e_int - s + 1; c = # components of M - K meeting K.  Then:
  (a) Delta V = -s, Delta E = -(e_int + e), Delta F = c - 1, Delta chi = -J with J := (e - c) + chi_K >= 0;
      Delta Phi = 2(e + chi_K - 1 - s); Delta Z <= e; |Delta rho| <= C(s + e).
  (b) Pinned(K) := some a in K has outdeg != indeg, or some component C of M - K has net flux != 0 from K.  Then k0 is
      a function of the charges, k0 = c_a/(out_a - in_a) or k0 = -(sum_{w in C} c_w)/flux_C.  Conversely, if K is
      unpinned, k0 -> k0 + t extends to a circulation (each C receives net 0 and is connected).  C2: the row-space test
      agrees with this formula in all 3000 cases.
  (c) Pinned => E_pre <= E_pos.  Restricting to M - K is injective, and its image lies in ONE parameter fiber:
      c'_w = c_w - (net multiplicity of w's bonds to K) k0, beta'_w = beta_w - (net multiplicity) |k0|^2, both
      functions of (c, beta).  Unpinned => E_pre <= #{k0} sup E_pos <= (2L+1)^d E_pos (fiberwise in k0).
  (d) Unpinned and every atom of K of degree 4 => J >= s + 1.  [Unpinned => every component gets an even number >= 2
      of bonds, so c <= e/2; and e = 4s - 2 e_int = 2s + 2 - 2 chi_K; so J >= e/2 + chi_K = s + 1.]  C2: min(J - s) = 1
      over 1005 unpinned all-degree-4 clusters.  Unpinned forces all atoms balanced, so all degrees are even.  At Op 5
      the degrees are 3 or 4 (4.2), so unpinned means all degree 4.
  (e) Deviation: I_K <= (log L)^{C(s+e)} (C1^{-1} delta^{1/2})^J L^{-(d-gamma) J} * [3^d L^d if unpinned].  The polylog
      factor comes from the ladder product (removing an atom changes O(1) ladders by O(1)) and from the X-factors in
      [1, (log L)^2].  This is the standard DH23 L1793 bookkeeping (not re-derived; see OPEN O3).
  (f) Required (the Op-5 analogue of excesseqn2, with the imperfect-component, Z and rho costs folded in, see 4.5):
        log_L I_K <= a (s - J) - eta e - C0 eta^5 (s + e).
      Pinned: the slack is (d - gamma - a) J + a s - eta e - ... >= (a - 4 eta - 5 C0 eta^5) s > 0, using e <= 4s.
      Unpinned: J >= s + 1 and e <= 2s + 2 <= 2J.  The slack is
        >= (d - gamma - a - 2 eta) J + a s - d >= 2(d - gamma - 2eta) - a - d = d - 2gamma - 2g0 - 4eta - 5eta^2
        >= 1 - 5eta > 0,
      using d >= 3 and gamma + g0 <= 1 (the same margin as remtame2's "d - 2gamma - 2g0 >= 1").
      E1 CHECKED: all 3000 sampled clusters plus synthetic worst cases (pinned J = 0, e = 4s; unpinned J = s + 1,
      e = 2s + 2; s < 40), for d = 3..6, gamma = 0.01..0.99, eta = g0/(1000 d).  Min slack 0.02.
  (g) The excluded cases, which cannot occur at Op 5, are exactly the bad ones: an unpinned degree-2 cycle atom (s = 1,
      J = 1, slack -gamma - 2eta < 0) and an isolated tame cycle (s = 2, J = 1, slack a - gamma < 0 for gamma >= 2/3).
      Both need damaged tame atoms, which T0 forbids.
  R27's single-atom table (research-remtame-i NOTES L4) is the case s = 1 of (f).
