# Blueprint (dated record)

The two planning documents written on 2026-11-03, at the start of the formalization: [`GRAPH.md`](GRAPH.md), the
node-level dependency graph of the proof of Theorem 1.1, and [`WAVE-B.md`](WAVE-B.md), the proposal for the second wave
of frozen statements. They are kept as written; the formalization later departed from them in places (see
[`../DECISIONS.md`](../DECISIONS.md) and [`../ERRATA-AND-DEVIATIONS.md`](../ERRATA-AND-DEVIATIONS.md)). They use the
project's internal work-package names. Lean names in them refer to the repository at the time of writing; a later
clean-up removed some unused helpers, which remain in the git history at the commits cited. Absolute local paths in these records were replaced in November 2026 by placeholders: `<scratch>/` (the project's private working directory), `<repo>/` (a checkout of this repository), `<worktrees>/` (development checkouts), `<sources>/` (a local copy of the papers' LaTeX sources and maps) and `<tools>/` (private tooling); none of these is part of the repository. Internal working records they cite (planning and audit records, working notes kept beside the Lean files, and the
agents' instructions) were removed from the repository at publication; those that were on the main branch remain in its git history.
